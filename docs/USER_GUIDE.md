# 黄金ETF技术分析系统 — 使用说明书

## 一、系统简介

本系统是一个A股ETF/股票技术分析平台，提供K线图表、技术指标分析、交易信号、模拟交易和自动交易功能。所有交易均为模拟，不涉及真实资金。

---

## 二、快速开始

### 2.1 注册与登录

1. 打开系统首页，自动跳转到登录页
2. 点击「注册」链接，输入用户名和密码（密码至少6位）
3. 注册成功后自动登录，跳转到看板页面
4. 后续访问使用用户名+密码登录

### 2.2 页面导航

系统顶部导航栏包含：

| 导航项 | 页面 | 功能 |
|--------|------|------|
| 看板 | DashboardView | 技术分析主页面 |
| 模拟交易 | SimulationView | 模拟账户+自动交易 |
| 系统设置 | SettingsView | 费率+刷新间隔配置 |

## 三、看板页面

### 3.1 搜索股票

- 在搜索栏输入6位股票代码（如 `518880`），系统自动识别交易所
- 支持快捷日期范围：近1月、近3月、近6月、近1年、近2年
- 默认加载黄金ETF（sh518880）近3个月数据

**交易所识别规则：**
- 6开头 → 上海（sh）：主板600/601/603、科创板688
- 000/002/003 → 深圳（sz）
- 300/301 → 创业板（sz）
- 8开头 → 北交所（bj）

### 3.2 信号条

显示当前交易信号状态：
- 🔴 **买入** — 建议买入
- 🟢 **卖出** — 建议卖出
- 🔵 **观望** — 暂无操作

同时显示实时价格、涨跌幅、RSI和KDJ状态。

### 3.3 网格策略卡片

展示网格交易策略分析结果：
- **网格可视化**：条形图显示当前持仓比例
- **基准均线**：可选MA5/MA10/MA20/MA60/MACD
- **关键数据**：建议持仓比例、网格区间、每格步长、ATR、偏离度

### 3.4 指标摘要卡片

6个核心指标一览：
1. **最新价** — 当前价格 + 涨跌幅
2. **MA5** — 短期趋势方向
3. **MA10** — 中期趋势 + 多空排列
4. **RSI** — 超买(>70)/超卖(<30)/正常
5. **KDJ J值** — 超买(>100)/超卖(<0)
6. **资金流向** — 累计净流入/流出

### 3.5 综合分析网格

汇总所有指标信号，给出综合建议：
- **偏多** — 多数指标看涨
- **偏空** — 多数指标看跌
- **观望** — 信号不明确

### 3.6 K线图

专业级K线图（基于TradingView lightweight-charts）：
- 主图：K线 + MA5/MA10/MA20 + 布林带上下轨
- 副图：成交量、MACD、KDJ 三图联动
- 支持十字光标、缩放、拖拽
- 实时价格自动更新当天K线

### 3.7 回测面板

基于历史数据的网格交易回测：
1. 设置初始资金（默认10万）
2. 选择网格数量（5/10/15/20格）
3. 选择网格区间（固定/ATR动态）
4. 选择基准均线
5. 点击「运行回测」
6. 查看结果：总收益率、最终资金、交易次数、胜率、最大回撤
7. 展开可查看资金曲线图和交易明细

## 四、模拟交易页面

### 4.1 账户概览

8个统计卡片展示账户状态：
- 初始资金、当前权益、总盈亏
- 可用资金、持仓市值、浮动盈亏
- 已实现盈亏、持仓笔数

**重置账户**：点击重置按钮，输入新的初始资金，清空所有持仓和记录。

### 4.2 手动下单

1. 输入证券代码（如 `518880`）
2. 选择方向：买入 / 卖出
3. 选择价格方式：实时价 / 自定义价
4. 输入数量（单位：手，1手=100股）
5. 确认下单

系统自动计算：
- 预计支出/收入（含手续费）
- 佣金（默认0.03%，最低5元）
- 印花税（卖出0.1%）
- 过户费（0.002%）

### 4.3 持仓管理

- 查看所有持仓：证券、数量、成本、当前价、市值、浮动盈亏
- 单条卖出：点击持仓行的卖出按钮
- 全部清仓：一键卖出所有持仓

### 4.4 成交记录

- 查看所有成交记录：时间、方向、证券、价格、数量、类型、手续费、盈亏
- 交易类型区分：手动(manual) / 自动(auto)
- 可清空历史记录

## 五、自动交易

### 5.1 概述

自动交易功能允许用户创建策略任务，系统后台调度器自动执行信号检测和下单操作。

**核心特点：**
- 后端统一调度，无需前端保持打开
- 服务重启后自动恢复运行中的任务
- 每个用户可创建多个任务（不同股票+策略组合）
- 完整的风控保护机制

### 5.2 创建任务

1. 在模拟交易页面，点击「+ 添加任务」
2. 填写任务配置：

| 配置项 | 说明 | 默认值 |
|--------|------|--------|
| 证券代码 | 6位股票代码 | — |
| 策略类型 | 5种策略可选 | 网格交易 |
| 每次仓位 | 单次交易仓位比例(0.1-1.0) | 1.0 |
| 检查间隔 | 信号检查频率(秒) | 30 |
| 分配资金 | 该任务的资金额度 | 30000 |
| 止损触发% | 亏损达到此比例清仓 | -5% |
| 止盈触发% | 盈利达到此比例清仓 | 10% |
| 最大回撤% | 回撤超过此比例暂停任务 | -15% |
| 动态间隔 | 根据波动率自动调整检查频率 | 关闭 |
| 已持有数量 | 初始持仓股数 | 0 |
| 持仓成本价 | 初始持仓成本 | 0 |

3. 根据策略类型，还需配置策略特有参数：

**网格交易 (grid)：**
- 基准均线：MA5/MA10/MA20/MA60
- 网格格数：5/10/15/20
- 网格幅度：0.01-0.50

**MA趋势跟踪 (ma_trend)：**
- 快线均线：MA5/MA10/MA20/MA60
- 慢线均线（趋势过滤）：可选

**布林带均值回归 (bollinger)：**
- 趋势过滤均线：可选

**RSI超买超卖 (rsi)：**
- 超卖阈值：默认30
- 超买阈值：默认70

**MACD金叉死叉 (macd_cross)：**
- 趋势过滤均线：可选

### 5.3 管理任务

- **启动**：点击任务卡片的「启动」按钮
- **停止**：点击运行中任务的「停止」按钮
- **编辑**：点击「编辑」修改任务配置（需先停止任务）
- **删除**：点击「删除」移除任务（需先停止任务）
- **全部启动/停止**：一键操作所有任务
- **拖拽排序**：拖动卡片左侧的 ⋮⋮ 手柄调整显示顺序

### 5.4 任务卡片信息

每个任务卡片显示：
- 证券名称/代码、策略类型、运行状态
- 实时价格和涨跌幅
- 当前信号（买入/卖出/观望）
- 基准均线、网格参数、检查间隔
- 分配资金、剩余可用
- 持仓/成本、已实现盈亏、浮动盈亏
- 止盈/止损阈值、最大回撤阈值
- 连续亏损次数（>0时显示冷却延长标签）

### 5.5 风控机制说明

| 机制 | 触发条件 | 动作 |
|------|----------|------|
| 止损 | 持仓亏损% ≤ 止损阈值 | 自动清仓 |
| 止盈 | 持仓盈利% ≥ 止盈阈值 | 自动清仓 |
| 最大回撤 | 净值从峰值回撤% ≤ 回撤阈值 | 自动暂停任务 |
| 连续亏损冷却 | 连续亏损1/2/3+次 | 冷却期延长至120/180/300秒 |
| 每日交易限制 | 当日交易次数 ≥ 上限 | 停止当日交易 |
| 信号确认 | 信号未连续2次相同 | 不执行交易 |
| 趋势过滤 | 逆势信号（可选） | 过滤不执行 |
| 交易日历 | 法定节假日/非交易时段 | 不执行交易 |

## 八、常见问题

### Q: 自动交易任务启动后没有交易？

检查以下条件：
1. 是否在交易时段内（09:30-11:30, 13:00-15:00）
2. 今天是否为交易日（非周末/节假日）
3. 信号是否连续2次相同
4. 是否在冷却期内
5. 模拟账户是否有足够资金
6. 仓位偏差是否达到最小调仓阈值（分配资金的2%）

### Q: 任务被自动暂停了？

可能原因：
1. **最大回撤保护**：净值从峰值回撤超过阈值（默认-15%），需手动重新启动
2. **账户资金归零**：模拟账户无现金，需重置账户

### Q: 冷却期为什么变长了？

连续亏损时冷却期自动延长：
- 0次亏损 → 原始冷却期（默认60秒）
- 1次亏损 → 120秒
- 2次亏损 → 180秒
- 3次+亏损 → 300秒

盈利交易后自动恢复原始冷却期。

### Q: 如何更换数据源？

系统自动按优先级切换数据源：新浪 → Tushare → 腾讯。如某个源失败，会自动尝试下一个，无需手动操作。

### Q: 支持哪些股票/ETF？

支持所有A股，包括：
- 沪市主板（600/601/603开头）
- 深市主板（000/002开头）
- 创业板（300开头）
- 科创板（688开头）
- 北交所（8开头）
- 各类ETF（如518880黄金ETF）

## 九、风险提示

1. 本系统所有交易均为**模拟交易**，不涉及真实资金
2. 技术指标和交易信号仅供参考，不构成投资建议
3. 历史回测收益不代表未来表现
4. 自动交易策略在极端行情下可能产生较大亏损
5. 请合理设置止损、止盈和最大回撤等风控参数
